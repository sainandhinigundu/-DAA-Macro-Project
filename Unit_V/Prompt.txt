Prompt used to generate the visualization (Project 13 - Knapsack Branch and Bound):

"Illustrate bounding and pruning in 0/1 Knapsack using node values. Use 4 items
(profits 40, 42, 25, 12 and weights 4, 7, 5, 3) with knapsack capacity 10.
Draw the state space tree where the left branch means INCLUDE an item and the
right branch means EXCLUDE it. In every node show the profit (p), weight (w) and
the upper bound (ub). Colour pruned nodes red, infeasible nodes orange, and the
path to the optimal solution green."

Tool used: Python + Matplotlib (the script Project13_Knapsack_BnB.py draws the
tree and saves it as Visualization.png).
